四方向覆盖

在整数格点 Z² 上放置棋子，要求横、竖、两条 45° 斜线四个方向都不出现连续 n 个棋子。等价地，每个方向的任意连续 n 格至少有一个空位。下面可以逐项查看已记录晶胞的具体平铺。

构造方法

所有坐标从 0 开始；未列为空位的格点全部放棋子；整数区间含两端；模运算取 0 到模数减 1 的代表元。普通 n×n 晶胞沿 (n, 0) 与 (0, n) 平铺。剪切晶胞用高度 H、宽度 W、剪切量 s 表示，周期向量为 (W, 0) 与 (s, H)：格点 (x, y) 先写成 y = qH + r（0 ≤ r < H），再归约到 ((x − qs) mod W, r)。

  1. 1　小参数 n = 1, 2, 3, 4, 9

    直接给出空位余数集合，均为单独构造。

    • n = 1全部留空。
    • n = 2x + 2y mod 4 ∈ {0, 1, 2} 时留空。
    • n = 3x + 2y mod 4 ∈ {0, 1} 时留空。
    • n = 4x + 2y mod 12 ∈ {0, 1, 5, 8} 时留空。
    • n = 9x + 30y mod 261 ∈ S 时留空，S 共 35 个元素。
    S = {0, 2, 9, 18, 20, 25, 27, 36, 43, 45, 52, 61, 70, 79, 88, 97, 106, 115,
     124, 127, 135, 144, 153, 162, 171, 179, 182, 191, 200, 209, 218, 227, 236, 245, 254}

  2. 2　线性同余族

    n ≡ 1, 5 (mod 6) 时取 p = n；n ≡ 0, 6, 8 (mod 12) 时取 p = n − 1。令 x + 2y ≡ 0 (mod p) 的格点留空，空位密度为 1/p。

    p 与 6 互素，四个方向对应步长 1、2、3、−1 在模 p 下都可逆，因此每个方向连续 p 格恰好有一个空位；p ≤ n 保证覆盖。n ≡ 1, 5 (mod 6) 时 p = n，该族达到已证下界 1/n。

  3. 3　两段斜率 3 的族

    适用 n ≡ 2, 10 (mod 12)，n ≥ 10。令 m = n/2，在 n×n 晶胞中：0 ≤ y < m 时留空 (3y mod n, y)；m ≤ y < n 时留空 ((3y + 3) mod n, y)；再补一点 (m, 0)。按 (n, 0)、(0, n) 平铺，共 n + 1 个空位。

    前半段用相位 0、后半段用相位 3，切换行用 (m, 0) 修补。相对原 1/(n − 1) 减少 1/[n2(n − 1)]；对 n ≡ 10 (mod 12) 相对 (n + 2)/n2 减少 1/n2。

  4. 4　n = 6k + 3 分段相位族

    适用 n ≥ 15。令 u = n/3，M = n(4n + 2)，a = 4n + 3。S 取下表所有 nq + r；当 x + ay mod M ∈ S 时留空。共 4n + 10 个余数，空位密度 (4n + 10)/[n(4n + 2)]。

    四个方向对应模 M 的步长 1、a、4n + 2、4n + 4。把各轨道空位换算为轨道坐标后，循环相邻间距均不超过 n，因此覆盖全部 n 长窗口。相对 (n + 2)/n2 减少 4/[n2(4n + 2)]。

  5. 5　两段斜率 2 的族

    适用 n ≡ 4 (mod 12)，n ≥ 16。令 h = n/2，在 n×n 晶胞内取：

    A = {((2y − 1) mod n, y) : 1 ≤ y ≤ h}
B = {(2(y − h + 1) mod n, y) : h − 1 ≤ y ≤ n − 1}
C = {(h, 0)}

    空位集合为 A ∪ B ∪ C，按 (n, 0)、(0, n) 平铺，共 n + 2 个空位。

    第一段用 x = 2y − 1，第二段用 x = 2(y − h + 1)，两段在切换行附近重叠，再补 (h, 0)，并集计数为 n + 2。

最优性：n = 1, …, 7 与 n ≡ 1, 5 (mod 6) 已证全局最优。其余 n 的记录只作为已实现的构造上界，尚未证明全局最优；两段斜率 3 族在普通 n×n 周期类别中的最优性，也不等于任意无限构造的全局最优性。

记录来自 50 个已保存晶胞，逐项做过四方向覆盖检查。δ 为已实现的空位密度，ρ = 1 − δ 是最大棋子密度的构造下界。
