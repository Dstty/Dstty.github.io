01 / 问题

一根不均匀燃烧的绳子，能告诉我们什么？

有若干根绳子，每根从一端点燃，烧完恰好需要一小时。但它们烧得不均匀：前半段可能烧了五分钟，后半段却要五十五分钟。你可以在起点，或观察到某根绳子燃尽时，点燃另一根绳子的一端或两端。没有钟，也不剪断、不熄灭绳子。

最著名的提问是：用两根绳子，怎样测出四十五分钟？

在同一时刻点燃第一根的两端、第二根的一端。第一根半小时后烧完，这时点燃第二根的另一端。第二根原本还需单端燃烧半小时，现在两端一起烧，只需再过十五分钟。于是，它燃尽时正好是第四十五分钟。

第二根：单端点火

45 分钟第二根燃尽
计时结束

这里用的是理想化燃烧模型：每一小段绳子有固定的燃烧时间，从哪一侧接近都一样；两处火焰同时燃烧，互不改变彼此的燃烧性质。两端点火使总燃烧时间减半，但火焰相遇的位置未必是长度的中点。

四十五分钟只是开头。真正的问题是：如果绳子足够多，我们能够制造哪些精确的燃尽时刻？把这些时刻从小到大排列，会出现什么结构？

02 / 从绳子到运算

为什么会出现 (a + b + 1) / 2？

把一小时记作一个时间单位。设一根绳子的两端分别在时刻 \(a\)、\(b\) 点燃，先假设 \(a\le b\)。到第二端点燃时，第一端已经烧了 \(b-a\) 个时间单位，所以剩余的“单端燃烧时间”为：

\[1-(b-a).\]

接下来两端一起烧，剩余时间再除以二。燃尽时刻就是：

\[T=b+\frac{1-(b-a)}2=\boxed{\frac{a+b+1}2}.\]

第二端点火时，绳子必须还没烧完，因此要求 \(b-a<1\)。不预先规定谁先点火时，条件写作 \(|a-b|<1\)。我们把这次操作记成“融合”：

\[a\sim b:=\frac{a+b+1}{2},\qquad |a-b|<1.\]

从时刻 \(0\) 出发，不断把已经得到的时刻拿来融合，形成全体可熔数，也就是这里所说的燃烧数，记作 \(\mathcal F\)。例如：

\[0\sim0=\frac12,\qquad 0\sim\frac12=\frac34,\qquad 0\sim\frac34=\frac78.\]

只点燃一端也没有增加新的可达时刻：从时刻 \(a\) 开始，连续使用两根双端点燃的绳子，同样能得到 \(a+1\)。不过两种做法消耗的绳子数不同。

这里研究的是时刻。第 30 分钟与第 45 分钟都是可识别时刻，两者之间隔了 15 分钟。但第 15 分钟本身并非从零出发可得到的燃尽时刻：任何一根完整绳子，最早也要半小时才能烧完。

03 / 一个寻找下一个时刻的算法

从融合公式到伪燃烧数函数

集合可以靠不断融合来生成，但若想回答“超过 \(x\) 的下一个点在哪里”，把所有融合表达式都列出来并不理想。我们先尝试一种有明确选择顺序的递归构造。

把它产生的点集记作 \(T\)，严格后继记作：

\[S(x)=\min\{t\in T:t>x\}.\]

“严格”意味着：即使 \(x\) 本身已经是一个点，也继续找比它大的那个点。对负数，最早的非负点是 \(0\)，所以规定 \(S(x)=0\)。

先把第一端安排得尽量早

若要一次融合的结果 \(z=a\sim b\) 超过 \(x\)，合法性给出 \(zx-1\)。这个策略便选择：

\[a=S(x-1).\]

固定了 \(a\)，条件 \((a+b+1)/2>x\) 等价于 \(b>2x-a-1\)。于是再选：

\[b=S(2x-a-1),\qquad S(x)=a\sim b.\]
这是构造策略，不是对全体燃烧数的贪心最优证明。第一端选得最早，并不自动保证最终融合结果在所有方案中最小。论文证明，这个递归恰好求出驯服可熔数集 \(T\) 的严格后继；\(T\) 是 \(\mathcal F\) 的真子集。本文称相关函数为“伪燃烧数函数”，文献记作 \(M\)。

把后继坐标换成“离后继还有多远”

定义间隙函数：

\[f(x)=S(x)-x,\qquad S(x)=x+f(x).\]

当 \(x<0\)，\(S(x)=0\)，立即得到 \(f(x)=-x\)。当 \(x\ge0\)，先把前面的 \(a\) 写成：

\[a=S(x-1)=x-1+f(x-1).\]

第二次调用的输入于是变成：

\[u=2x-a-1=x-f(x-1).\]

接着 \(b=S(u)=u+f(u)\)，代回融合公式：

\[\begin{aligned}S(x)&=\frac{a+b+1}{2}\\&=\frac{a+(2x-a-1)+f(u)+1}{2}\\&=x+\frac{f(u)}2.\end{aligned}\]

减去 \(x\)，就得到那条看起来颇为神秘的递归：

\[\boxed{f(x)=\begin{cases}-x,&x<0,\\[2mm]\dfrac12f\bigl(x-f(x-1)\bigr),&x\ge0.\end{cases}}\]

它的每个部分都有来源：\(x-1\) 来自合法融合的时间窗口，内层的减法来自对第二端阈值的反解，最外面的二分之一来自双端燃烧。

这里的代数变形解释了公式如何产生；递归在所有实数上终止、且确实得到 \(T\) 的后继，则是论文证明的定理。仅凭“每次输入都变小”还不足以证明实数递归终止，因为实数中存在无限严格下降链。

手算几个值

\[\begin{aligned}f(0)&=\tfrac12f(-1)=\tfrac12,\\f(\tfrac12)&=\tfrac12f(0)=\tfrac14,\\f(\tfrac34)&=\tfrac12f(\tfrac12)=\tfrac18,\\f(1)&=\tfrac12f(\tfrac12)=\tfrac18.\end{aligned}\]

比如最后一行中，\(f(0)=1/2\)，所以外层递归的输入是 \(1-f(0)=1/2\)。函数值不是下一个点的坐标，而是距离：\(S(1)=1+1/8=9/8\)。

用精确分数直接计算 
from fractions import Fraction
from functools import cache

@cache
def f(x):
    if x < 0:
        return -x
    return f(x - f(x - 1)) / 2

print(f(Fraction(1)))  # 1/8

这是定义的直接实现，适合小输入。应使用精确分数；浮点舍入可能让“本来大于零的极小间隙”消失。数学终止性也不等于实际运行成本很小。

05 / 从数点到数顺序

“前面有多少个间断点”，为什么要用序数？

若只问点的个数，下面这些无限初段都只是可数无穷，基数都是 \(\aleph_0\)。但它们的排列方式并不一样：有的是一条无限序列，有的是无限多条无限序列接在一起，有的还包含更高层的聚集。

序数记录的正是这种顺序结构。我们从零编号，定义：

\[r(a)=\operatorname{ot}\bigl(D\cap[0,a)\bigr),\qquad a\in D.\]

这里 \(\operatorname{ot}\) 表示按实数大小排列后的序型，右端点 \(a\) 本身不计入。用 \(\Phi\) 表示反向对应，即 \(\Phi(r(a))=a\)。

第一层：ω 是一整条无限序列

在 \(1\) 之前，间断点恰好为：

\[\Phi(n)=1-2^{-n}\quad(n=0,1,2,\ldots).\]

因此 \(0\) 编号为 0，\(1/2\) 编号为 1，\(3/4\) 编号为 2，依次类推。所有有限编号用完后，这些点的极限 \(1\) 获得编号：

\[r(1)=\omega.\]

\(\omega\) 不是“最大的自然数”，它是全部自然数按通常次序排成的一条序列的序型。在这条序列后面再放一个点，才得到 \(\omega+1\)。

第二层：一块 ω，再接一块 ω

在 \(1\) 之后，最初的一块是：

\[1,\ \frac98,\ \frac{19}{16},\ \frac{39}{32},\ldots\ \longrightarrow\ \frac54.\]

这些点的编号依次是 \(\omega,\omega+1,\omega+2,\ldots\)，所以 \(5/4\) 的编号是 \(\omega\cdot2\)。再往后还有第三块、第四块……它们的边界也在聚集。

更精确地，对 \(k\ge1\)、\(n\ge0\)，初始的这些块满足：

\[\Phi(\omega k+n)=\frac32-2^{-(k+1)}-2^{-(k+n+1)}.\]

固定 \(k\)，让 \(n\) 增大，会走完一条 \(\omega\) 长的序列；再让 \(k\) 增大，无限多块接起来，得到 \(\omega\cdot\omega=\omega^2\)。因此：

\[r\!\left(\frac32\right)=\omega^2.\]

第三层：把“无限多块”继续当成块

层级继续增长，出现 \(\omega^3,\omega^4,\ldots\)。对于正整数 \(n\)，有：

\[\Phi(\omega^n)=2-2^{1-n}.\]

对应的实数是 \(1,3/2,7/4,15/8,\ldots\)，趋向 \(2\)；序数则趋向 \(\sup_n\omega^n=\omega^\omega\)。于是：

\[r(2)=\omega^\omega.\]

端点约定会改变答案。\([0,1)\) 的间断点序型是 \(\omega\)，\([0,1]\) 则是 \(\omega+1\)。同样，\(r(2)=\omega^\omega\) 表示 \(2\) 之前的点，不包括 \(2\) 本身。序数加法还依赖顺序：\(1+\omega=\omega\)，但 \(\omega+1>\omega\)。

间断点的聚集，也可以分层

先把所有孤立点去掉，只留下聚点；再对剩下的集合做同样操作，就得到“聚点的聚点”。如此继续，必要时在极限阶段取此前各层的交集。这叫 Cantor–Bendixson 导集过程。

编号为后继序数的点在 \(D\) 中是孤立点；编号为非零极限序数的点是聚点。\(1\) 的编号是 \(\omega\)，属于第一层聚点；\(3/2\) 的编号是 \(\omega^2\)，是第二层；\(2\) 的编号是 \(\omega^\omega\)，层数已经是 \(\omega\)。

更一般地，把非零编号写成康托标准形：

\[\alpha=\omega^{\alpha_1}c_1+\cdots+\omega^{\alpha_k}c_k,\qquad \alpha_1>\cdots>\alpha_k.\]

点 \(\Phi(\alpha)\) 的聚点层数恰好是最后一个指数 \(\alpha_k\)，约定孤立点为第 0 层。例如 \(\omega^2+\omega\) 最后一项的指数是 1，所以 \(25/16\) 是第一层聚点。这里说的是点集的聚集层级；这些点本身仍然全部是函数的跳跃间断点。

06 / 有限绳子与超限结构

为什么整套编号走到了 ε₀？

前面的对应不是巧合。论文第四节引理 24 给出关键结构定理：对每个 \(a\in D\)，

\[\boxed{r(a+1)=\omega^{\,1+r(a)}.}\]

它把实数轴上的“往后移动一小时”，变成了序数上的“取一个以 \(\omega\) 为底的幂”。注意指数里的 \(1+r(a)\) 是序数加法，顺序应当保留。对于无限编号，\(1+r(a)=r(a)\)。

这条结构定理从哪里来？

驯服集合的定义给出一种有序复制规则。取相邻点 \(p

\[u\longmapsto q\sim u=\frac{q+u+1}{2}.\]

这个映射保持点的先后顺序，同时把距离减半。于是每个新时间窗口里，都出现了无限多份旧结构。顺次接起 \(\omega\) 份，是序数的右乘 \(\omega\)；当边界本身也是旧结构的极限时，再取序数上确界。

例如，\(p=0,q=1/2\) 时，把 \([1/2,1)\) 里的无限序列复制到 \([1,5/4)\)，再复制到 \([5/4,11/8)\)，如此形成 \(\omega\) 块，并逼近 \(3/2\)。这解释了 \(3/2\) 前为什么会有 \(\omega^2\) 型的点。

对这种复制过程作超限归纳，便得到上面的结构定理。这里给出的是证明机制；完整的窗口不变量与极限步骤见论文第四节，不能仅凭一张有限分辨率的图来代替。

整数位置，依次对应越来越高的幂塔

\[\begin{aligned}r(0)&=0,\\r(1)&=\omega,\\r(2)&=\omega^\omega,\\r(3)&=\omega^{\omega^\omega},\\r(4)&=\omega^{\omega^{\omega^\omega}},\quad\ldots\end{aligned}\]

设 \(\tau_1=\omega\)，\(\tau_{n+1}=\omega^{\tau_n}\)。则 \(r(n)=\tau_n\)，这些有限高度幂塔的上确界是：

\[\varepsilon_0=\sup_{n\ge1}\tau_n.\]

它也是满足 \(\omega^\alpha=\alpha\) 的最小正序数。每个有限实数都在某个整数之前，而整数对应的编号已经在 \(\varepsilon_0\) 中共尾，所以：

\[\boxed{\operatorname{ot}(D)=\varepsilon_0.}\]

这里没有一个有限坐标对应“第 \(\varepsilon_0\) 个点”。\(\varepsilon_0\) 描述整个无界间断点集的序型；各个点的编号都严格小于它。每个具体点依然由有限构造给出，但所有有限构造按大小合在一起，就形成了超限的顺序结构。

序数告诉我们结构，不承诺计算容易

点 \(3\) 的编号仅需写成 \(\omega^{\omega^\omega}\)，可它到下一个点的距离却是：

\[f(3)=2^{-1541023937}.\]

因此，短小的递归式很快就会产生极端微小的间隙。论文还证明：这个递归对所有实数输入都终止，但“它对所有自然数输入都终止”这一统一命题在皮亚诺算术 PA 中不可证明。单个输入的计算与全体输入的统一终止证明，是不同层面的问题。

从燃绳问题出发，我们先得到一个平均运算，再得到后继与间隙，最后在间断点的聚集方式里读出序数。真正把它们连起来的，是同一条规则的反复作用：把已有的时间结构缩小，再按顺序复制。
