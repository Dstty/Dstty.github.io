Research Note

环面 de Bruijn 构造

在环面上放 k 种颜色的格子，要求每个 r×s 窗口读出的图案互不相同。窗口位置数等于图案总数时，全部图案恰好各出现一次，这样的环面就是 de Bruijn 环面。下面三个实例分别覆盖 16、64、81 种窗口图案，都可以点选窗口、按编码反查位置。

读法与约定

  • 行列下标从 0 开始，越界时对边长取模，也就是把平面卷成环面。
  • 窗口按行优先读取：先上排从左到右，再下一排。
  • 二进制按 2 的幂加权、三进制按 3 的幂加权，得到窗口编码。
  • 窗口数等于图案总数时，编码恰好是 0 到 N−1 的一个排列。
窗口 编码 0 · (1, 1)

点小窗口里的一格切换颜色，大图会框出对应图案的位置

01 · 4×4 · 双色 · 2×2 窗口

(4, 4; 2, 2)₂

16 个格子里正好 8 个黑格，16 个 2×2 窗口读出 0000 到 1111 各一次。


      
穷举全部 C(16, 8) = 12870 个八黑格矩阵共得 32 个解，在环面平移、转置翻转、黑白互换下全部等价，所以这个构造在对称意义下本质唯一。

03 · 9×9 · 三色 · 2×2 窗口

      
(9, 9; 2, 2)₃

      
9×9 = 81 个窗口，正好对上 3⁴ = 81 种 2×2 三色图案。首行与首列都是 012012012，三种颜色各出现 27 次。

      

      
这个显式解由 CP-SAT 在“81 个窗口编码两两不同”的约束下求得。9×9 是奇数环面，不能直接套棋盘奇偶的计数论证；首行首列固定为 012012012 只是选定的一个代表。

    

  


  

    
验证与备注

    
对每个矩阵，遍历全部窗口位置、按行优先读出编码并去重，与 krs 比较即可判定是否为 de Bruijn 环面。页面加载时也用同一套逻辑重新算了一遍，三者的窗口数分别是 16、64、81，去重后数量与之相等。

一般地，k 种颜色、r×s 窗口的 de Bruijn 环面需要 krs 个窗口位置，且格子数必须等于这个数。
