Research Note

道路阵列的四种构造

每个格子从中心向若干个方向伸出道路，相邻两格在相反方向上的状态必须一致，阵列之外不得有路伸出。下面四个实例都满足：每格编号恰好覆盖全部状态各一次、边界封闭、有路格全连通。

统一规则

  • 每格一个中心，路从中心伸到格子边的中点；斜向道路伸到角点，与对角邻格的路相接。同格的所有路在中心相通。
  • 相邻两格在一对相反方向上必须同时有路或同时无路；双色版本还要求颜色一致。邻格在阵列之外时，该方向必须无路。
  • 状态按固定朝向区分：只有向上的路与只有向右的路是两种状态，不合并旋转或镜像。
  • “所有道路连通”指任取一段路都能到达其余道路。每个方案都有一个完全无路的格子，连通性只覆盖其余格子。
  • 八方向图中两条斜线在四格公共角点交叉时按立交理解，不额外连接；给出的解在此基础上已经连通。

02 · 八方向 · 单色 · 16×16

      
2⁸ = 256 个状态各出现一次

      
每个方向独立取有路或无路，权值依次为上 1、右上 2、右 4、右下 8、下 16、左下 32、左 64、左上 128。24 = 8 + 16 表示右下、下有路；255 表示八向全有路。

      

      
0～255 各出现一次，所有水平、竖直、对角方向均与邻格匹配，外圈无路伸出；除左上无路格外 255 格连通，不依赖斜线交叉额外接通。

03 · 六方向 · 单色 · 64 格正六边形

      
8×8 辅助矩阵到正六边形的同构重绘

      
辅助坐标中用上、右、左上、下、左、右下六个出口，权值依次为 1、2、4、8、16、32，共 2⁶ = 64 种状态。42 = 2 + 8 + 32 表示辅助坐标中的右、下、右下有路。

      

      
绘制时第 r 行第 c 列的中心取 x = d(c − r/2)、y = d(√3/2)·r，六边形边长 d/√3、上下各一个顶点。于是六种邻接关系正好变成六个共边邻接。

      
一一对应保证 64 种状态仍各出现一次，匹配与连通关系不变，外边界仍封闭。

04 · 四方向 · 双色 · 9×9

      
3⁴ = 81 个状态各出现一次

      
每格只向上、右、下、左伸路，每个方向可取无路、蓝路、橙路之一，同一方向至多一种颜色。编号为四位三进制数：上×1 + 右×3 + 下×9 + 左×27，位值 0 无路、1 蓝、2 橙。

      
21 = 0×1 + 1×3 + 2×9 + 0×27，即右蓝、下橙；80 四位全 2，四向全橙；40 四位全 1，四向全蓝。

      
蓝路橙路

      

      
同格两色可在中心相接换色。按这一约定，除左上无路格外 80 格全部连通；蓝路、橙路各自单独全连通是更强的要求，本实例没有验证。

    

  


  

    
这些实例如何求得

    
4×4 用逐格回溯：从左上角按行填入未用过的状态，放之前检查边界和已放的上方、左方邻格，不满足就换下一个状态，用尽则回退。填完再做一次图遍历，只有覆盖全部 15 个非空格才接受。

    
更大规模改用邻格连接上的随机局部搜索：

    
    
      
  1. 枚举内部允许的无向邻格连接，每对邻格只记一次，不建立通向阵列外部的连接。
    2. 
      
  2. 固定左上角为无路格，不建立与它相连的道路。
    3. 
      
  3. 为每条内部连接随机赋状态（单色 0/1，双色 0/1/2），两端同步使用这一状态。
    4. 
      
  4. 从每格周围的连接反推编号，统计各编号出现次数。代价取各次数 n 对应的 n(n−1)/2 之和。
    5. 
      
  5. 每次随机挑一条连接改状态，用模拟退火决定是否保留，以跳出局部最优。
    6. 
      
  6. 代价降到 0 即所有编号不重复；格子数等于状态数时也就意味着恰好各一次。再检查连通性后接受。
    7. 
    

    
相邻匹配和边界封闭在这种表示下始终成立，搜索只处理状态唯一性。随机搜索不保证任意规模都能找到解，存在性依据仍是给出的具体矩阵与验证。

三个容易混淆的点：空格不参与连通性要求；八方向解的连通性不依赖交叉斜线额外接通；双色解采用允许在格子中心换色的连通定义。
